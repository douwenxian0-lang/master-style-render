# master-style-render

> 把「某位设计大师的设计语言」变成可参数化调用的生图指令——不是让 AI 自由发挥，而是**锁死风格 DNA 后出图**。

## 这是什么

一个室内/建筑设计 AI 效果图的**风格控制系统**。

市面上大多数 AI 生图的做法是"描述风格"——写"高端大气""现代简约"，然后祈祷模型理解对了。这个 Skill 换了个思路：把 18 位设计大师的风格拆解成**可计算的风格 DNA**（材质配比、色彩逻辑、光线规则、家具语言、空间秩序），再用四个参数自动组装成生图提示词。

**结果差别**：同样是"梁志天风格的客厅"，自由描述出来的图每次都长得不一样；锁死 DNA 后，同一套参数跑十次，风格是稳定的。

## 核心能力

| 模块 | 说明 |
|------|------|
| **风格库** | 8 位室内设计大师 + 10 位建筑设计大师，每位含完整风格 DNA + 英文提示词块 + 负向词。支持自定义风格提取（附实测案例） |
| **参数组装** | 「空间 × 改动程度 × 大师风格 × 光线」四参数，CLI 一行命令出 prompt |
| **铺贴系统** | 材质高保真（L1/L2/L3 三级）+ 砖缝可控（5 档位），**专门解决瓷砖类材质的还原度问题** |
| **生图引擎** | 对接 ImageGen / Nano Banana Pro / ComfyUI，改动程度决定保留原结构的强度 |

## 为什么需要「改动程度」这个参数

这是本方法里最关键、也最容易被忽略的一个开关。

做旧改升级时，最大的风险不是风格不对，而是**AI 把房子画变形了**——墙的位置变了、窗户多了、空间比例错了。根因是模型不知道哪些部分必须保留。

`改动程度` 参数（软装更换 / 轻度翻新 / 中度改造 / 重新装修）控制的正是图生图时对原图结构的保留强度。它不直接影响画面好看程度，但直接决定了**出来的图能不能用**。

## 铺贴系统：砖缝是 AI 的尺子

做瓷砖/石材类效果图时，AI 判断纹理尺度的唯一依据，就是画面里的砖缝与砖规格。

- 写 `large-format tile floor` → AI 只能猜尺度 → 纹理假、缝错、砖块比例乱
- 写 `1200x600 slabs, tight 1mm joints` → 纹理尺度、缝宽、砖块比例同时对齐

**规格 + 缝宽是尺度锚，不是装饰细节。** 这是本 Skill 相对通用生图方案的核心增量。

材质还原度三级方案：

- **L1** 纯提示词 → 60–70%
- **L2** 图生图 + 产品图 → ~80%
- **L3** 真实产品纹理贴图 → 100%（终局方案）

## 快速开始

```bash
# 基础四参数
python scripts/build_prompt.py --space 客厅 --level 重新装修 --master 梁志天 --light 傍晚暖光

# 带铺贴系统（推荐：规格+缝宽是尺度锚）
python scripts/build_prompt.py -s 客厅 -l 重新装修 -m 孙建亚 --light 清早晨曦 \
  --tile 水泥灰 --gloss 柔光 --format 750x1500 --grout 密缝 --bond 大板通铺 --surface 地面
```

prompt 结构固定：

```
[画质] + [改动指令] + [空间描述] + [大师风格DNA] + [铺贴系统] + [光线] + [机位] + [渲染质感] + [负向]
```

## 三个入口

1. **旧改升级**（最常用）— 上传现状照片 + 四参数 → 出效果图
2. **效果风格迁移** — 现有效果图 + 意向参考图，双图输入，推荐 Nano Banana Pro
3. **建筑外观风格迁移** — 建筑线稿/照片 + 建筑大师风格（公建 / 文旅住宅 / 文化建筑各有推荐人选）

## 关键原则

- **风格 DNA 优先于形容词** — 不写"高端大气"，写材质、色彩、光线、家具语言
- **方向描述用上/下/左/右** — 不用东南西北（与图纸对齐更准确）
- **大师风格 ≠ 抄图** — 学的是设计语言，不是复制某个项目
- **一次一变量** — 比风格就换大师重跑，不要在一个 prompt 里混两位大师
